Стратегия Blue/Green — Hub-Solo работает рядом со старым хабом

Hub-Solo запускается на новом эндпоинте POST /webhook/v2. Переключение источника = смена одного URL в настройках (AmoCRM / Avito-бот / форма лендинга). Откат при сбое — 30 секунд. avito-telegram-bot и 24filldoc не трогаются до Фазы 2. Старый путь «источник → AmoCRM напрямую» остаётся как fallback на весь период миграции.

Слой 1 — Источники лидов (4 подтверждённых канала)

🌐 Лендинг krona-park

  • POST /webhook/v2 (Hub-Solo) Фаза 1
  • Поля: имя, телефон
  • UTM из URL (?utm_source=…)
  • Страница захвата, IP
  • Honeypot-защита от спама

🏠 Avito.ru

  • avito-telegram-bot (Python)
  • Фаза 1: → АМО напрямую (без изменений)
  • Фаза 2: → POST /webhook/v2
  • Avito-переписка: ответ через бота
  • Привязка к ID объявления

📞 Входящий звонок

  • АТС webhook → /webhook/v2
  • Caller ID → нормализация
  • Запись разговора → URL
  • Пропущенный → задача «перезвонить»
  • Автоответ недоступен (звонок)

💬 Telegram / Max

  • Telegram-бот → webhook → /webhook/v2
  • Max (VK) → webhook → /webhook/v2
  • chat_id сохраняется для ответа
  • Авто-ответ через тот же канал
  • Сохранение диалога в примечание

📦 Оффлайн / сарафан

  • Ввод вручную оператором в АМО
  • Выставка, буклет, рекомендация
  • Тег «сарафан» проставляется вручную
  • Хаб не задействован
Слой 2 — Hub-Solo (FastAPI + SQLite + APScheduler) — единая точка сборки

📥 Webhook Receiver

  • FastAPI POST /webhook/v2
  • Секрет в URL (bearer token)
  • Ответ 200 немедленно, обработка async
  • SQLite: лог всех входящих
  • Retry: exponential backoff (2–16 с)
  • Единый формат из всех источников

🔍 Нормализация и валидация

  • Телефон → +7XXXXXXXXXX
  • Имя: strip, title-case
  • Источник: avito / lp / call / tg / max
  • UTM: source / medium / campaign
  • Рабочие часы: 09:00–20:00 МСК
  • Нерабочие → флаг delayed

🔄 Бессрочная дедупликация v2

  • Поиск по телефону — без временного окна
  • Контакт найден → обновить, не создавать
  • Счётчик касаний + дата последнего
  • Открытая сделка → добавить примечание
  • Закрытая сделка → создать новую
  • История всех источников сохраняется

⚡ Авто-первое-касание НОВОЕ

  • Ответ через канал входа — немедленно
  • Avito: через avito-telegram-bot API
  • Telegram: через Bot API (chat_id)
  • Max: через VK Messaging API
  • Квалифицирующий текст: площадь + дата
  • Рабочие часы → обычный ответ
  • Нерабочие → «Свяжусь в 9:00»

⏱️ Планировщик follow-up

  • APScheduler (в процессе FastAPI)
  • Само-напоминание +15 мин (TG оператору)
  • Само-напоминание +1 ч (усиленное)
  • Само-напоминание +4 ч (критическое)
  • Post-показ +1 день, +3 дня
  • Сезонная реактивация (cron март)
Слой 3 — AmoCRM API v4 — последовательность вызовов

🔍 Поиск дубля GET

  • /api/v4/contacts?query={phone}&with=leads
  • Без временного окна — всегда
  • → 404: создать контакт
  • → 200 + открытая сделка: обновить
  • → 200 + закрытая сделка: создать новую

👤 Контакт POST

  • /api/v4/contacts
  • name, phone (+7…), тип WORK
  • telegram_chat_id (custom field)
  • tags: [источник]
  • responsible_user_id: ID оператора (константа)

📋 Сделка POST

  • /api/v4/leads
  • name: «КП — {имя} — {источник}»
  • pipeline_id: воронка v2
  • status_id: «Новый лид»
  • responsible_user_id: оператор

🏷️ Custom Fields PATCH

  • UTM Source / Medium / Campaign
  • Источник лида (список)
  • Объект интереса / площадь
  • Страница захвата (URL)
  • Telegram / Max chat_id
  • Avito объявление ID

✅ Задача-напоминание POST

  • /api/v4/tasks
  • responsible_user_id: оператор (константа)
  • «Позвонить новому лиду» — now+15 мин
  • Если delayed → завтра 09:00
  • entity_type: «leads», entity_id

📝 Примечание POST

  • /api/v4/leads/{id}/notes
  • note_type: «common»
  • Полный текст сообщения клиента
  • UTM, IP, страница, время
  • Ответ авто-первого-касания

Слой 5 — Автоматизация соло (триггеры от АМО → хаб, APScheduler)

⚡ Авто-первое-касание КЛЮЧЕВОЙ

  • Немедленно при создании лида
  • «Получил заявку. Пока набираю —»
  • «1. Площадь? 2. Когда показ?»
  • Avito → ответ в Avito-чат
  • Telegram → ответ в Telegram
  • Max → ответ в Max
  • Нерабочие часы → «в 9:00»

🔔 Само-напоминания v2

  • TG оператору (не РОПу!)
  • +15 мин: «Не забудь позвонить»
  • +1 ч: «Лид ждёт, срочно!»
  • +4 ч: «Критично — клиент может уйти»
  • Звонок сделан → напоминания отменяются

📍 Автоматизация показа

  • Триггер: этап «Показ назначен»
  • Ответ через канал входа клиента
  • Адрес + ссылка на krona-park («как добраться»)
  • Напоминание за 2 часа до показа
  • Напоминание оператору за 30 мин

📋 Пост-показ follow-up

  • Триггер: этап «Показ состоялся»
  • День +1: «Как впечатления от участка?»
  • День +3 (нет ответа): «Остались вопросы?»
  • Задача оператору: уточнить решение

📄 24filldoc — ПДКП + ДКП v2

  • Триггер: «Бронь / задаток» → ПДКП
  • Триггер: «Договор ДКП» → основной договор
  • Данные из сделки АМО → шаблон
  • DOCX → PDF → прикрепить к сделке
  • Отправить клиенту через TG / Max
  • 24filldoc сервис не трогается

🔁 Реактивация v2

  • +30 дней: «Новые участки появились»
  • Каждый март: вся база отказов за 2 года
  • APScheduler cron: 0 9 1 3 *
  • Сегментация по причине отказа
  • Через тот же канал входа
Слой 6 — 4 метрики рычага + еженедельный отчёт (не дашборды)

⏱️ Время первого касания

  • Авто-касание: 0–5 сек
  • Звонок оператора: медиана
  • Цель: авто < 10 с, звонок < 30 мин
  • Тренд по неделям

★ Конверсия «Показ→Бронь»

  • Главная метрика для земли
  • Цель: > 25%
  • Разбивка по источнику лида
  • Сезонный тренд

💰 CPL по каналу

  • Avito / Лендинг / Звонок / TG+Max
  • Куда направлять бюджет
  • Лид до показа (не просто заявка)

📊 Еженедельный TG-отчёт

  • Понедельник 9:00, TG оператору
  • Новые / Показы / Брони / Отказы
  • % лидов, дошедших до показа
  • Конверсия за неделю vs прошлая

🗺️ Дорожная карта внедрения Hub-Solo (3 фазы — не строить всё сразу)

ФАЗА 1 — MVP · 1–2 дня

Базовый приём лидов

  • FastAPI POST /webhook/v2
  • Нормализация телефона и имени
  • Создание контакта + сделки в АМО
  • TG-уведомление оператору
  • Авто-первое-касание (шаблонный текст)
  • Подключить: только лендинг-форма
  • Старый хаб работает для Avito/звонков
ФАЗА 2 — Автоматизация · 3–5 дней

Показ и follow-up

  • Бессрочная дедупликация (SQLite)
  • Само-напоминания оператору (+15м/+1ч/+4ч)
  • Авто-подтверждение показа + маршрут
  • Пост-показ follow-up (День +1, День +3)
  • APScheduler в процессе FastAPI
  • Подключить: avito-telegram-bot → /webhook/v2
  • Подключить: телефония, Telegram/Max
ФАЗА 3 — Полная автоматизация · 1–2 нед.

Сделка и аналитика

  • 24filldoc: ПДКП (Бронь) + ДКП (Договор)
  • Еженедельный TG-отчёт по 4 метрикам
  • Сезонная реактивация (APScheduler март)
  • Реактивация +30 дней
  • Запрос отзыва после закрытия (+7 дней)
  • Отключение старого хаба (если есть)

⚡ Авто-первое-касание — тексты по каналу и времени суток

Рабочие часы (9:00–20:00) — любой канал
«Здравствуйте! Получил вашу заявку по участкам Крона Парк.
Пока набираю номер — ответьте на 2 вопроса:
1. Площадь? (6 / 8 / 10 / 12 соток)

Нерабочие часы (20:00–9:00)
«Спасибо за интерес к Крона Парк!
Заявку получил, но сейчас нерабочее время.
Свяжусь с вами завтра в 9:00.
Чтобы сразу подобрать участок — напишите, какая
площадь интересует?»
Повторный лид (дубль — контакт уже есть)
«Рад вас снова видеть!
Мы уже общались по участкам Крона Парк.
Появились новые вопросы или хотите назначить показ?»
Avito — ответ в Avito-переписку
Канал: avito-telegram-bot API
Метод: ответ в тред объявления
Важно: ответ идёт от имени продавца в Avito,
не из внешнего мессенджера
Telegram — ответ через bot.send_message

Сохраняется в custom field сделки АМО
Max (VK Messenger) — ответ через API
POST vk.com/method/messages.send
peer_id: user_id из события
Токен сообщества VK / Max API

🔌 Последовательность API-вызовов Hub-Solo → AmoCRM

1. Поиск контакта GET
GET /api/v4/contacts?query={phone}&with=leads
→ нет: создаём контакт → сделку
→ открытая сделка: добавляем примечание
→ закрытая сделка: создаём новую сделку
2. Создание контакта POST
POST /api/v4/contacts
[{name, custom_fields_values: [phone, email],
tags: [{name: source}],
responsible_user_id: OPERATOR_ID}]
3. Создание сделки POST
POST /api/v4/leads
[{name: "КП — {name} — {source}",
pipeline_id: PIPELINE_V2,
status_id: STATUS_NEW,
responsible_user_id: OPERATOR_ID}]
4. Custom fields PATCH
PATCH /api/v4/leads/{id}
custom_fields_values: [utm_source, utm_campaign,
source, object_type, capture_url,
chat_id, avito_ad_id]
5. Привязка контакт → сделка POST
POST /api/v4/leads/{id}/links
[{to_entity_type: "contacts",
to_entity_id: contact_id,
metadata: {main_contact: true}}]
6. Задача оператору POST
POST /api/v4/tasks
[{task_type_id: 1,
text: "Позвонить новому лиду",
complete_till: now+(900 или до 09:00),
entity_type: "leads", entity_id}]
7. Примечание POST
POST /api/v4/leads/{id}/notes
[{note_type: "common", params: {text:
"Источник: {source}\nUTM: {utm}\n
Ответ авто-касания: {auto_reply_text}"}}]
8. Webhook АМО → Hub-Solo WEBHOOK
POST /webhook/amo-events
leads[status]: смена этапа → триггер автоматизации
Этап «Показ назначен» → confirm + маршрут
Этап «Бронь» → 24filldoc ПДКП
Этап «Договор» → 24filldoc ДКП

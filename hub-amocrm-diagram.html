Слой 1 — Источники лидов (входящие каналы)

🌐 Лендинг Крона-Парк

  • HTML-форма, POST /api/lead
  • Поля: имя, телефон, email
  • UTM из URL (?utm_source=…)
  • Referrer / страница захвата
  • reCAPTCHA / honeypot защита
  • IP, User-Agent, время

🏠 Avito.ru

  • avito-telegram-bot (Python)
  • Мониторинг входящих в Avito
  • Парсинг: имя, телефон, текст
  • Webhook → хаб (POST)
  • Привязка к объявлению
  • Отслеживание показов

📞 Входящий звонок

  • Виртуальная АТС (Манго / Zadarma)
  • Callback-виджет на LP
  • Webhook при вызове → хаб
  • Определение номера (caller ID)
  • Запись разговора → URL
  • Пропущенные → перезвон

💬 Telegram-бот

  • @kronaParkBot команда /start
  • Кнопки: «Узнать цену», «Записаться»
  • Сбор: имя, телефон, вопрос
  • chat_id для обратной связи
  • Вебхук Telegram → хаб
  • Пересылка медиа / документов

📱 WhatsApp / Viber

  • WazzUp или GreenAPI
  • Входящее сообщение → вебхук
  • Парсинг текста запроса
  • Автоответ-визитка менеджера
  • Сохранение диалога в примечание

👤 Ручной ввод

  • Менеджер напрямую в АМО
  • Выставка / оффлайн-событие
  • Визитка → сделка вручную
  • Рекомендация (тег «сарафан»)
Слой 2 — Хаб (Integration Hub) — центральный обработчик

📥 Webhook Receiver

  • HTTPS endpoint (nginx + TLS)
  • Проверка подписи (HMAC-SHA256)
  • Помещение в очередь (Redis)
  • Rate limiting (IP + source)
  • Дедлайн ответа: 200ms
  • Логирование raw-запроса
  • Retry при сбое обработчика

🔍 Парсинг и валидация

  • Извлечение UTM (source / medium / campaign / term / content)
  • Нормализация телефона → +7XXXXXXXXXX
  • Очистка имени (спецсимволы, регистр)
  • Валидация email (RFC-5322)
  • Определение источника по домену реферрера
  • Время суток → рабочие / нерабочие часы

🔄 Дедупликация

  • GET /contacts?query={phone} в АМО
  • GET /contacts?query={email} в АМО
  • Временное окно дубля: 24 часа
  • Дубль → обновить сделку vs создать новую
  • Merge: добавить примечание к старой сделке
  • Счётчик касаний по лиду

🗺️ Маппинг данных

  • Источник → тег АМО (avito / lp / звонок / tg / wa)
  • UTM campaign → название рекламной кампании
  • Время → менеджер по расписанию
  • Объект интереса → custom field «Участок»
  • Регион → менеджер по территории
  • Бюджет из текста → поле «Бюджет»

⚙️ Бизнес-логика

  • Рабочие часы: 09:00–20:00 МСК
  • Нерабочие → очередь + SMS «Перезвоним в 9:00»
  • Round-robin по свободным менеджерам
  • Лид-скоринг: телефон > email > анонимный
  • Эскалация если задача не взята > 5 мин
  • Эскалация на РОПа если > 30 мин
Слой 3 — AmoCRM API v4 — создание сущностей

👤 Контакт POST

  • /api/v4/contacts
  • name: «Имя Фамилия»
  • phone: +7XXXXXXXXXX (тип WORK)
  • email: адрес (тип WORK)
  • tags: [источник, utm_source]
  • custom_fields: telegram_chat_id
  • responsible_user_id: менеджер

📋 Сделка POST

  • /api/v4/leads
  • name: «Крона Парк — [имя]»
  • pipeline_id: ID воронки
  • status_id: «Новый лид» (этап 1)
  • price: бюджет из запроса
  • responsible_user_id: менеджер
  • created_at: UNIX timestamp

🏷️ Поля сделки PATCH

  • /api/v4/leads/{id}
  • UTM Source / Medium / Campaign
  • Источник лида (list-поле)
  • Объект интереса (text)
  • Площадь участка (int)
  • Страница захвата (url)
  • Telegram Chat ID (int)

🔗 Привязка контакта POST

  • /api/v4/leads/{id}/links
  • to_entity_type: «contacts»
  • to_entity_id: contact_id
  • metadata.main_contact: true
  • Один контакт → много сделок

✅ Задача POST

  • /api/v4/tasks
  • task_type_id: 1 (Позвонить)
  • text: «Перезвонить новому лиду»
  • entity_type: «leads»
  • entity_id: lead_id
  • complete_till: now() + 5 минут
  • responsible_user_id: менеджер

📝 Примечание POST

  • /api/v4/leads/{id}/notes
  • note_type: «common»
  • Полный текст запроса клиента
  • IP-адрес, UserAgent
  • URL страницы захвата
  • Все UTM-параметры
  • Время создания

Слой 5 — Уведомления и автоматизация (триггеры от АМО → хаб)

🤖 Telegram → Менеджер

  • Триггер: новый лид (мгновенно)
  • Сообщение: имя, телефон, источник
  • Inline-кнопки: «Принять» / «Занят»
  • Ссылка на сделку в АМО
  • Триггер: просрочена задача > 5 мин
  • Эскалация → РОП при > 30 мин

📲 WhatsApp / SMS → Клиент

  • Триггер: получение заявки → подтверждение
  • «Ваша заявка принята, ждите звонка»
  • Триггер: этап «Показ участка»
  • Адрес объекта + ссылка на маршрут
  • Напоминание за 2 часа до показа
  • Контакт менеджера (имя, тел)

📄 Генерация ДКП

  • Триггер: этап «Договор»
  • Интеграция с 24filldoc (Python)
  • Подтягивание данных из сделки АМО
  • Авто-заполнение DOCX шаблона
  • Конвертация в PDF
  • Отправка клиенту + прикрепление к сделке

🔁 Реактивация лидов

  • Триггер: этап «Нереализовано»
  • Задача реактивации через 30 дней
  • SMS/WhatsApp: «Новые предложения»
  • Повторный прогрев через 60 дней
  • Сегментация по причине отказа

📊 Ежедневный отчёт

  • Каждый день в 18:00 МСК
  • Telegram → менеджеры + РОП
  • Новые / в работе / закрыты / отказы
  • Конверсия по источникам за день
  • Просроченные задачи
  • KPI менеджеров (звонки, задачи)
Слой 6 — Аналитика и метрики

📈 UTM-аналитика

  • CPL по источнику (стоимость лида)
  • Конверсия LP по кампании
  • ROAS на рекламные каналы
  • Avito vs Google vs Yandex

🔢 Воронка

  • Конверсия на каждом этапе
  • Среднее время жизни в этапе
  • Dropout-анализ (где теряем)
  • Время от заявки до звонка

👥 KPI команды

  • Скорость первого отклика
  • Закрытые сделки / менеджер
  • Просроченные задачи
  • NPS клиентов (отзывы)

🗂️ Сегментация

  • Горячий / тёплый / холодный лид
  • Бюджет клиента (до 1 млн / 1-3 / 3+)
  • Объект интереса (соток / дом)
  • Гео-регион запроса

🔌 Полный список API-вызовов Хаб → AmoCRM (последовательность)

Шаг 1 — Поиск дубля по телефону GET
GET /api/v4/contacts?query={phone}&with=leads
→ 404: контакт не найден, создаём
→ 200: контакт есть, смотрим сделки
Шаг 2 — Поиск дубля по email GET
GET /api/v4/contacts?query={email}&with=leads
Выполняется параллельно с шагом 1
→ Объединяем результаты
Шаг 3 — Создание контакта POST
POST /api/v4/contacts
Body: [{name, first_name, last_name,
custom_fields_values: [{phone}, {email}],
tags: [{name: source}]}]
Шаг 4 — Создание сделки POST
POST /api/v4/leads
Body: [{name: "Крона Парк — {name}",
pipeline_id, status_id,
responsible_user_id, price}]
Шаг 5 — Custom fields сделки PATCH
PATCH /api/v4/leads/{lead_id}
custom_fields_values: [{utm_source},
{utm_medium}, {utm_campaign},
{source}, {object}, {budget}, {page}]
Шаг 6 — Привязка контакта → сделка POST
POST /api/v4/leads/{lead_id}/links
[{to_entity_type: "contacts",
to_entity_id: {contact_id},
metadata: {main_contact: true}}]
Шаг 7 — Задача «Позвонить» POST
POST /api/v4/tasks
[{task_type_id: 1, text: "Позвонить новому лиду",
entity_type: "leads", entity_id: lead_id,
complete_till: now + 300 (5 мин)}]
Шаг 8 — Примечание с деталями POST
POST /api/v4/leads/{lead_id}/notes
[{note_type: "common",
params: {text: "Источник: {source}\nUTM: ...\nIP: ...\nСтраница: ..."}}]
Шаг 9 — Webhook АМО → Хаб WEBHOOK
POST /webhook/amocrm (исходящий из АМО)
События: leads[status] — смена этапа
leads[update] — изменение поля
tasks[add/complete] — задачи
Шаг 10 — Обновление статуса сделки PATCH
PATCH /api/v4/leads/{id}
[{status_id: {new_stage_id},
responsible_user_id: {manager_id}}]
→ Вызывается хабом при обработке событий

🏷️ Custom Fields сделки в AmoCRM — полный список

UTM Source
Тип: список
Значения: google / yandex / avito / telegram / vk / direct / organic / referral
UTM Medium
Тип: текст
Значения: cpc / cpm / social / email / referral / none
UTM Campaign
Тип: текст
Пример: krona-park-2026 / land-summer / retargeting
UTM Content
Тип: текст
Пример: banner-top / cta-form / sidebar
Источник лида
Тип: список
Значения: LP форма / Avito / Входящий звонок / Telegram / WhatsApp / Ручной ввод
Объект интереса
Тип: список
Значения: Участок 6 сот / 8 сот / 10 сот / 12 сот / Дом под ключ / Не определено
Бюджет клиента
Тип: список
Значения: до 1 млн / 1–3 млн / 3–5 млн / 5–10 млн / от 10 млн
Страница захвата
Тип: URL
Пример: https://krona-park.ru/?utm_source=avito&utm_campaign=...
Telegram Chat ID
Тип: число
Используется для обратных уведомлений клиенту через бота
Дата первого касания
Тип: дата-время
Автозаполняется хабом при создании лида
Номер объявления Avito
Тип: число
ID объявления на Avito.ru — для отслеживания источника
Причина отказа
Тип: список
Дорого / Не подошёл объект / Уже купил / Не выходит на связь / Другое
